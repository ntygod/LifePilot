# 文档处理常见问题

| 现象 | 常见原因 | 处理 |
|---|---|---|
| 中文乱码 | 输入编码不是 UTF-8 | 先检测编码，CSV 优先用 `utf-8-sig` 读写 |
| PDF 转文本为空 | 扫描件或图片型 PDF | 需要 OCR；先说明当前工具无法直接抽取可选中文 OCR |
| pandoc 生成 PDF 失败 | 缺 PDF engine / 字体 | 改用 HTML 中间文件，或安装 wkhtmltopdf / xelatex |
| Word 表格丢失 | Markdown 表格解析能力不足 | 用 pandoc 或直接 python-docx 写表格 |
| Excel 数字变文本 | CSV 全按字符串导入 | 用 openpyxl 明确类型，必要时对列做类型转换 |
| 文件被占用 | Office 正在打开目标文件 | 让用户关闭文件，或写到新路径 |
| 路径含空格失败 | shell 参数未正确引用 | 用引号包路径，批处理脚本中使用数组/参数化 |
| 批量转换部分失败 | 个别文件损坏或格式差异 | 记录失败清单，跳过失败文件继续处理 |

失败时优先保留中间文件和日志，不要覆盖原始输入。
