# 调研路径决策

4 条路径按判据分流。

## 1. 快速答（"X 是什么 / 了解一下 X"）

判据：用户要一句话答案，没要求对比/分析/时效。
→ web.search 1 次，1-3 句直答 + 1 个来源。
错例：用户问"X 和 Y 选哪个"——这是深度对比。

## 2. 深度对比（"X vs Y / 选什么 / 推荐什么"）

判据：用户要在多个方案里挑一个。
→ 广度搜识别候选 → 深度搜差异点 → web.fetch 抓正文核对（不看摘要就动笔是错例）→ 对比表/SWOT/推荐。

## 3. 趋势/动态（"X 最近怎么样 / 最新进展"）

判据：用户关心时间维度。
→ query 显式带年份/"最新" → 逐条核对发布日期，过期剔除 → 时间线+关键节点输出。
注意：web.search 没有时间过滤参数，时效全靠 query 关键词。

## 4. 事实核查（"这个数字对吗 / 是真的吗"）

判据：用户给了具体断言。
→ 搜正反两面 → 抓至少 2 个独立来源正文 → 有共识给确认+双源，分歧明示而非择一。
硬约束：关键数据 ≥2 个独立来源（同公司/同作者/互相转载不算独立）。

## 输出格式

| 场景 | 格式 |
|------|------|
| 快速答 | 1-3 句 + 1 个来源链接 |
| 选型对比 | 对比表 + 推荐与适用场景 |
| 竞品分析 | SWOT/功能矩阵 |
| 趋势 | 时间线（日期+事件+来源） |
| 事实核查 | 结论 + 证据链 |
| 跨多源研究 | 章节结构 + 参考文献列表 |

## 来源标注

正文行内：`<事实>（[<标题>](<URL>)）`。只有搜索摘要、抓不到正文时标"来源：搜索摘要，未经原文核对"。

## 常见错误

- 搜索 0 命中 → 同义词/拆短关键词/切中英文，2 次仍空就告知，不编造
- web.fetch 正文空 → 换 selector，仍空加 renderJs=true，仍空告知
- 付费墙 → 标"来源被遮挡"，换公开来源
- 多源结论冲突 → 明示分歧，不择一掩盖
- 数据陈旧 → 告知最新证据缺失
- 用户给的 URL 抓不动 → 先试 renderJs=true，仍失败问用户
