# Cron 调度参考

> action 参数与命令模板见 tool schema。本文档仅含 cron 特有领域知识。

## Cron 表达式速查（Spring 6 位 = 秒 分 时 日 月 周）

`* = 每个`、`*/n = 每 n 个`、`a-b = 范围`、`a,b,c = 列举`、`?` 用于日/周二选一。**不是 Linux 5 位**。

| 表达式 | 含义 |
|--------|------|
| `0 0 8 * * *` | 每天 8:00 |
| `0 30 9 * * MON-FRI` | 工作日 9:30 |
| `0 0 9,18 * * *` | 每天 9 点和 18 点 |
| `0 0 */2 * * *` | 每 2 小时整点 |
| `0 */15 * * * *` | 每 15 分钟 |
| `0 0 8 * * MON` | 每周一 8:00 |
| `0 0 10 * * SAT,SUN` | 每周末 10:00 |
| `0 0 8 1 * *` | 每月 1 号 8:00 |
| `0 0 8 L * *` | 每月最后一天 8:00 |

**用户表达 → cron**："每天早上 8 点"→`0 0 8 * * *`，"每隔 30 分钟"→`0 */30 * * * *`，"每周三晚上 9 点"→`0 0 21 * * WED`

## 静默协议

例行检查无异常时回复 `TASK_SILENT`（任意位置出现即可），有结果时直接汇报。Cron 表达式无效时检查是 6 位、周用大写 MON-SUN。
