# Implementation Plan: eliminate-hardcoding

## Overview

将 LifePilot 中已识别的硬编码常量提取到 `@ConfigurationProperties` 配置类 + `application.yml`，并更新编码规范。按配置层→消费层→自动配置层→配置声明→规范文档的顺序实施，每步增量可验证。

    - 新增 `TokenBudget` 嵌套类，包含 10 个配置字段及 getter/setter
    - 字段：systemPromptRatio(0.10f)、userMessageRatio(0.15f)、highRelevanceWorkingMemory(40.0f)、highRelevanceRetrieval(35.0f)、longConversationWorkingMemory(60.0f)、longConversationRetrieval(15.0f)、defaultWorkingMemory(50.0f)、defaultRetrieval(25.0f)、highRelevanceThreshold(0.9f)、longConversationTurnsThreshold(10)
