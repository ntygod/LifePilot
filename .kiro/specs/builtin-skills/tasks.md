# Implementation Plan: builtin-skills

## Overview

按依赖顺序实现 Skill 框架核心和三个内置 Skill：数据模型 → 事件模型 → 异常层次 → 记忆访问控制 → 校验器 → 注册中心 → 搜索索引 → SubAgent 工厂 → 生命周期管理 → 工具桥接 → Flyway 迁移 → 持久化层 → 内置 Skill 提供者 → 注册器 → 自动配置 → 集成测试。

所有服务通过 @Bean 注册，不使用 @Service/@Component。中文注释、Javadoc、日志消息、异常消息、测试方法名。

## Notes

- Tasks marked with `*` are optional and can be skipped for faster MVP

- Checkpoints ensure incremental validation
- Property tests (jqwik) validate universal correctness properties from the design document
- Unit tests validate specific examples and edge cases
- All services registered via @Bean in SkillAutoConfiguration, not @Service/@Component
- SkillToolAdapter uses BuiltinTool to avoid modifying sealed ToolContract
