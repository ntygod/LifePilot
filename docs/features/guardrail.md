# 安全护栏 — 特性说明

> **文档性质**：特性说明文档
> **模块归属**：`com.lifepilot.guardrail` + `com.lifepilot.observability.guardrail`
> **最后更新**：2026-03

## 1. 功能概述

安全护栏系统在 LLM 之外强制执行工具调用的安全策略，确保高风险操作经过适当的审批和审计。通过四级风险分级和可插拔策略机制，在不影响正常使用体验的前提下保障系统安全。

## 2. 核心特性

### 2.1 四级风险分级

- **LOW**：自动执行，无额外检查（如查询待办列表）
- **MEDIUM**：自动执行 + 审计记录（如修改日程）
- **HIGH**：需用户确认后执行（如删除数据）
- **CRITICAL**：需用户确认 + 二次验证（如执行系统命令）

### 2.2 可插拔策略

通过 GuardrailPolicy 接口定义安全策略，支持运行时动态注册和注销。每个策略有独立的优先级，按优先级顺序执行。

### 2.3 Spring AI Advisor 集成

GuardrailAdvisor 作为 Spring AI Advisor 横切注入 ChatClient 调用链，在 LLM 调用前后自动执行护栏检查，对业务代码无侵入。

### 2.4 工具白名单

支持配置工具白名单，白名单内的工具跳过护栏检查，适用于已验证安全的内置工具。

## 3. 使用场景

Agent 在执行工具调用前，护栏系统自动检查工具的风险等级。低风险工具直接执行，高风险工具弹出确认提示等待用户审批。所有 MEDIUM 及以上级别的工具调用都会记录审计日志。

## 4. 配置项

| 配置键 | 默认值 | 说明 |
|--------|--------|------|
| `lifepilot.guardrail.enabled` | `true` | 是否启用护栏系统 |

## 5. 限制与未来方向

- 当前用户确认机制依赖交互渠道（CLI / Web），非交互渠道暂不支持 HIGH/CRITICAL 级别工具
- 未来计划：支持基于上下文的动态风险评估、策略规则 DSL
