# Agent Skills 技能系统

> 本文档从 [FEATURES.md](../FEATURES.md) 拆分而来，对应原文 §2.2 章节。

> ✅ Skill 系统已实现（Phase 3，模块 10）。当前实现需要重构以对齐业界 Agent Skills 标准。
> 详细架构设计参见 [architecture/skill-system.md](../architecture/skill-system.md)。

ZhiWei 采用业界标准的 Agent Skills 架构。Skill 是**程序性知识包（Procedural Knowledge Package）**——包含领域专业指令、参考资料和脚本。当 Skill 被激活时，其指令注入 Agent 上下文，Agent 按照指令使用 LLM 推理执行任务。

## 1. Skill 的本质

MCP 提供"专业工具"（Agent 能做什么），Skill 提供"操作手册"（Agent 应该怎么做）。

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| 指令（instructions） | 领域专业指令，Markdown 格式 | "你是专业的写作助手，写作风格简洁有力..." |
| 建议工具（suggestedTools） | 建议 Agent 优先使用的工具 | `[searchMemory, createDocument]` |
| 参考资料（references/） | 辅助参考文档 | 写作风格指南、模板文件 |
| 脚本（scripts/） | 辅助脚本 | 大纲生成模板 |

Skill 与 Agent 的关键区分：
- Skill = 操作手册（没有独立推理能力，注入宿主 Agent 上下文）
- Agent = 独立执行者（有自己的 LLM、上下文、预算，由模块 21 AgentDefinition 定义）
- 需要独立人格和持续对话的角色（写作助手、健身教练、财务分析师）应使用 AgentDefinition

## 2. 四种 Skill 来源

| 来源 | 定义方式 | 加载时机 | 适用场景 |
|------|---------|---------|---------|
| **Builtin** | Java 代码提供指令 | 系统启动时注册 | 核心能力指令 |
| **UserDefined** | SKILL.md 文件夹 | 运行时热加载 | 用户自定义 + 社区 Skill |
| **AutoGenerated** | Agent LLM 生成 | 安全验证后注册 | Agent 自动学习新能力 |
| **Marketplace** | 从市场安装 | 安装时注册 | 第三方 Skill 分发 |

## 3. SKILL.md 文件夹结构

兼容 Anthropic Agent Skills 开放标准，社区 Skill 可直接使用：

```
~/.lifepilot/skills/
├── writing-assistant/
│   ├── SKILL.md              # 指令文件（必需）
│   ├── scripts/              # 辅助脚本（可选）
│   ├── references/           # 参考资料（可选）
│   └── assets/               # 资产文件（可选）
└── fitness-coach/
    ├── SKILL.md
    └── references/
```

## 4. Skill 激活与执行

Skill 激活 = 将指令注入 Agent 上下文。Agent 使用自己的 LLM 按照指令推理执行。


**使用示例：**

```
你：帮我写一篇关于本周工作进展的周报

ZhiWei：好的，我来帮你准备周报。

         🔍 发现匹配 Skill：writing-assistant
         📋 激活「写作助手」Skill，加载写作指令...

         📊 正在收集本周数据...
         - 本周完成 8 项待办，2 项延期
         - 参加 5 场会议（含 2 场客户会议）
         - 习惯打卡完成率 85%

         ✍️ 按照写作指令撰写周报...

         📝 周报草稿：
         
         【本周工作总结】
         一、重点工作完成情况
         1. XX项目Q1评审材料已提交（周二完成）
         2. 客户需求文档 v2.0 已交付（周四完成）
         ...
         
         需要我调整内容或风格吗？
```

## 5. SKILL.md 定义示例

```markdown
---
id: writing-assistant
name: 写作助手
description: 擅长长文撰写、润色、翻译，能结合用户的知识库生成高质量内容
version: "1.0.0"
suggested_tools:
  - searchMemory
  - queryKnowledgeBase
  - createDocument
tags:
  - writing
  - content
category: productivity
---

# 写作助手

你是一个专业的写作助手。你的写作风格简洁有力，善于用数据说话。

## 工作流程

1. 先从用户的记忆和知识库中获取相关素材
2. 根据素材和用户需求拟定大纲
3. 按大纲逐段撰写
4. 完成后进行润色和校对

## 写作原则

- 数据驱动：用具体数据支撑观点
- 简洁有力：避免冗余表达
- 结构清晰：使用标题和列表组织内容
```

## 6. Skill 自扩展能力

当现有 Skill 无法处理用户请求时，Agent 自动生成新的 SKILL.md，经过三重验证（格式 → 安全 → 沙箱）后注册。

```
你：帮我查一下今天人民币对美元的汇率

ZhiWei：检测到当前没有汇率查询能力，正在创建新 Skill...
         🔍 分析需求：需要调用汇率 API 获取实时数据
         📝 生成 Skill 定义：exchange-rate/SKILL.md
         🔒 安全验证：✅ 格式校验通过 ✅ 安全检查通过 ✅ 沙箱验证通过
         
         💱 今日汇率：1 USD = 7.24 CNY
         
         [此 Skill 已保存到 ~/.lifepilot/skills/，下次可直接使用]
```

## 7. 渐进式发现

受 Anthropic Agent Skills 标准启发，三阶段加载机制节省 86% 上下文消耗：

| 阶段 | 加载内容 | Token 消耗 |
|------|---------|-----------|
| Discovery | name + description | ~40 Token/Skill |
| Activation | 完整指令 + 建议工具 | 500-2000 Token（仅选中的 Skill） |
| Execution | Agent 按指令推理执行 | 由 Agent 预算控制 |

## 8. 社区兼容性

ZhiWei 的 Skill 格式与 Anthropic Agent Skills 开放标准兼容。社区发布的 SKILL.md 文件夹可直接放入 `~/.lifepilot/skills/` 目录使用，无需任何转换。
