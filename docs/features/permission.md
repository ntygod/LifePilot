# 工具权限系统 — 特性说明

> **文档性质**：特性说明文档
> **模块归属**：`com.lifepilot.permission`
> **最后更新**：2026-03

## 1. 功能概述

工具权限系统把高风险工具执行改成“授权模型”而不是“每次弹确认”。

对用户来说，当前行为可以概括为：

- 普通读写类操作大多可直接执行
- 高风险操作第一次需要授权
- 授权后，相同范围内的同类操作可以复用
- 无人值守任务必须先拿到预授权

## 2. 核心特性

### 2.1 四类授权主体

- **SESSION**：当前会话内复用
- **WORKSPACE**：当前项目或目录范围复用
- **TASK**：当前定时任务、心跳或工作流复用
- **USER**：长期授权，跨会话复用

### 2.2 动作级授权

工具不会直接按工具 ID 暴露给用户，而是先被映射成更容易理解的动作类型，例如：

- `READ_FILE`
- `WRITE_FILE`
- `EXECUTE_SHELL`
- `HTTP_REQUEST`
- `CREATE_SCHEDULE`
- `GENERIC_TOOL_OPERATION`

### 2.3 作用域匹配

授权记录可以带作用域信息，用来限制授权覆盖范围，例如：

- 文件路径或工作区目录
- 网络 origin / host
- 数据集合名
- 定时任务 ID

这使得“允许当前项目下执行命令”和“允许任何目录执行命令”成为两种不同授权。

### 2.4 聊天内授权

在 Web 对话里，遇到高风险工具时：

1. 系统先检查是否已有匹配授权
2. 未命中则通过 SSE 发起授权请求
3. 用户批准后立即继续执行

日常使用时，大多数授权都建议在聊天里完成。

### 2.5 任务级预授权

如果创建的 Cron、Heartbeat 或自主工作流后续会执行高风险动作，系统会在创建阶段一次性申请任务级预授权。授权成功后：

- 后续自动运行不再重复弹窗
- 授权只对当前任务生效
- 不会自动放开其他任务

### 2.6 授权管理 API 与设置页

Web 端提供授权管理能力，支持：

- 查询当前有效授权
- 手动创建高级授权
- 撤销授权
- 查看任务预授权覆盖范围

## 3. 使用场景

### 场景 1：项目内高风险命令

你第一次在某个工作区执行高风险命令时需要授权；之后相同工作区内的同类命令可以直接复用。

### 场景 2：定时整理文件

如果某个 Cron 任务需要定期写文件或删除旧文件，创建任务时先完成任务级预授权，后续运行无需人工介入。

### 场景 3：长期个人授权

对于你已经明确接受的高风险能力，可以创建长期授权，减少跨会话重复审批。

## 4. 当前约束

- 自主执行场景不会在运行时临时交互授权
- 任务级预授权只覆盖当前任务，不会扩散到其他任务
- 低中风险默认放行，但仍会经过统一的权限记录与护栏链路
