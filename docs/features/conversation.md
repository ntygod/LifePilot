# 对话系统 — 特性说明

> **文档性质**：特性说明文档
> **模块归属**：`com.lifepilot.conversation`
> **最后更新**：2026-03-20

## 1. 功能概述

对话系统现在承担两件很明确的事：

- 把原始消息可靠地写进会话层
- 给上层提供统一的最近轮次和完整时间线读取能力

它不再负责“从 L2 补回当前会话历史”，也不再参与旧版 L1/L2 对话缓存逻辑。

## 2. 核心特性

### 2.1 当前会话最近轮次读取

- `ContextAssembler` 通过 `ContextEngine` 获取最近完整轮次
- 返回结果已经按完整 turn 裁剪，适合直接拼进 Prompt

### 2.2 完整时间线展示

- Web UI 通过 `ChatSessionService` 读取会话完整消息流
- 返回值按时间正序排列，适合直接渲染聊天记录

### 2.3 对话真源单一化

- 原始消息统一保存在 `chat_messages`
- 这让“当前聊了什么”这个问题只需要看会话层，不需要再和 L1/L2 对齐

### 2.4 与记忆分层解耦

- 当前会话连续性来自 conversation 模块
- 跨会话 recall 来自 memory 模块
- 两者职责分开后，调用链和问题定位都更简单

## 3. 使用场景

### 3.1 Agent 组装上下文

`ContextAssembler` 每轮调用前从 transcript 条目中读取最近完整轮次，把当前 session 的真实上下文拼进 Prompt。

### 3.2 Web UI 展示历史

前端打开某个会话时，通过 `ChatSessionService.getSessionMessages(...)` 直接渲染完整聊天历史。

### 3.3 评估与回放

评估组件可以复用 transcript 读模型读取消息时间线，避免直接绑定数据库表结构。

## 4. 当前限制

- 模块只负责当前会话的读取与展示，不负责跨会话召回
- 对话编辑、删除等高级操作仍不在该模块职责内
- 最近轮次是否完整，取决于消息角色和轮次分组规则是否正常
