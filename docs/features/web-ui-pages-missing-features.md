# Web UI 功能页面缺失功能分析

> **分析日期**：2026-02-27  
> **分析范围**：知识库、技能、轨迹、工作流四个管理页面

---

## 1. 知识库管理页面 (KnowledgeBaseView.vue)

### ✅ 已实现功能
- 知识库列表展示（卡片视图）
- 创建知识库（名称、描述）
- 删除知识库
- 文档列表展示
- 文档上传（点击选择文件）
- 删除文档
- 文档状态显示（PENDING/PROCESSING/COMPLETED/ERROR）

### ❌ 缺失功能

#### 1.1 文档上传体验
- **拖拽上传**：文档提到支持拖拽上传，但代码中只有点击上传
- **批量上传**：无法一次选择多个文件上传
- **上传进度显示**：大文件上传时没有进度条，用户不知道上传状态
- **上传队列管理**：无法查看正在上传的文件列表

#### 1.2 文档管理
- **文档预览**：无法查看文档内容（PDF预览、Markdown渲染等）
- **文档搜索**：无法在知识库内搜索文档（按文件名、内容）
- **文档重命名**：无法修改文档名称
- **文档重试处理**：失败状态的文档无法重新处理
- **批量操作**：无法批量选择删除多个文档
- **文档排序**：无法按名称、大小、时间排序

#### 1.3 知识库配置
- **分块策略配置**：无法配置 Fixed/Recursive/Heading 分块策略
- **Embedding 模型配置**：创建时无法选择 Embedding 模型（后端支持但前端未暴露）
- **知识库编辑**：无法修改知识库名称和描述
- **知识库统计**：缺少更详细的统计信息（总大小、向量数量、检索次数等）

#### 1.4 文档分块查看
- **分块列表**：无法查看文档的分块详情
- **分块内容预览**：无法查看每个分块的具体内容
- **分块重新处理**：无法重新分块或调整分块参数

#### 1.5 其他
- **知识库搜索**：无法在知识库列表中搜索
- **知识库筛选**：无法按创建时间、文档数量筛选
- **知识库统计图表**：缺少可视化统计（文档数量趋势、存储占用等）

## 2. Skill / MCP 管理页面 (SkillManageView.vue)

### ✅ 已实现功能
- Skill 列表展示（卡片视图）
- Skill 详情查看（抽屉）
- Skill 注销（非 Builtin）
- MCP Server 列表展示
- MCP Server 连接/断开
- MCP 工具列表查看

### ❌ 缺失功能

#### 2.1 Skill 管理
- **Skill 启用/禁用**：文档提到支持开关控制，但前端未实现（后端可能也缺少）
- **Skill 搜索**：无法搜索 Skill（按名称、描述、工具名）
- **Skill 筛选**：无法按来源类型（Builtin/UserDefined/AutoGenerated）筛选
- **Skill 创建**：无法在前端创建新的 Skill（需要 YAML 文件）
- **Skill 编辑**：无法修改 Skill 配置（需要修改 YAML 文件）
- **Skill 测试**：无法测试 Skill 的执行效果
- **Skill 使用统计**：无法查看 Skill 的使用频率、成功率等

#### 2.2 MCP Server 管理
- **MCP Server 配置**：无法查看/编辑 MCP Server 配置
- **MCP Server 日志**：无法查看连接日志、错误日志
- **MCP Server 搜索**：无法搜索 MCP Server
- **MCP Server 状态监控**：无法实时查看连接状态变化
- **工具详情**：点击工具只能看到名称和描述，无法查看工具参数、示例等

#### 2.3 其他
- **批量操作**：无法批量启用/禁用多个 Skill
- **Skill 依赖关系**：无法查看 Skill 之间的依赖关系
- **工具使用统计**：无法查看工具的使用频率

---

## 3. 轨迹回放页面 (TraceReplayView.vue)

### ✅ 已实现功能
- 轨迹列表展示（分页）
- 轨迹详情查看
- 步骤展开/收起
- 步骤详情查看（工具输入/输出、动作 JSON）
- Token 统计显示
- 时间线视图

### ❌ 缺失功能

#### 3.1 轨迹查询
- **轨迹搜索**：无法搜索轨迹（按用户消息、工具名、错误信息）
- **轨迹筛选**：无法按成功/失败、时间范围、模型、Token 范围筛选
- **轨迹排序**：只能按时间倒序，无法按耗时、Token 数排序

#### 3.2 轨迹分析
- **性能分析**：无法查看各步骤的耗时分布、瓶颈分析
- **Token 分析**：无法查看 Token 消耗的详细分布（按步骤、按模型）
- **错误分析**：无法统计错误类型、错误频率
- **工具使用统计**：无法查看哪些工具使用最频繁、哪些工具失败率最高

#### 3.3 轨迹导出
- **导出 JSON**：无法导出轨迹为 JSON 文件
- **导出 Markdown**：无法导出为可读的 Markdown 报告
- **分享链接**：无法生成分享链接（如果支持多用户）

#### 3.4 轨迹对比
- **轨迹对比**：无法对比两条轨迹的差异
- **轨迹回放动画**：无法以动画形式回放执行过程

#### 3.5 其他
- **实时跟踪**：文档提到不支持实时跟踪，这是未来扩展项
- **轨迹标记**：无法标记重要轨迹、添加备注
- **轨迹收藏**：无法收藏常用轨迹

## 4. 工作流管理页面 (WorkflowManageView.vue)

### ✅ 已实现功能
- 工作流列表展示
- 工作流详情查看
- 启用/禁用工作流
- 手动触发工作流
- 执行历史查看

### ❌ 缺失功能

#### 4.1 工作流查询
- **工作流搜索**：无法搜索工作流（按名称、描述、触发器类型）
- **工作流筛选**：无法按启用状态、触发器类型筛选
- **工作流排序**：无法按创建时间、执行次数排序

#### 4.2 执行历史管理
- **执行历史分页**：执行历史列表可能很长，需要分页
- **执行详情查看**：无法查看单次执行的详细步骤
- **执行日志查看**：无法查看执行过程中的日志输出
- **执行重试**：失败的执行无法重新触发
- **执行取消**：运行中的执行无法取消

#### 4.3 工作流编辑
- **YAML 编辑器**：文档提到不支持在线编辑，这是限制项
- **工作流创建**：无法在前端创建新工作流（需要 YAML 文件）
- **工作流复制**：无法复制现有工作流

#### 4.4 工作流监控
- **执行统计**：无法查看工作流的执行次数、成功率、平均耗时
- **执行时间线**：无法查看工作流的执行时间线图表
- **触发器状态**：无法查看定时触发器的下次执行时间
- **工作流依赖**：无法查看工作流之间的依赖关系

#### 4.5 其他
- **工作流测试**：无法测试工作流的执行（不实际触发）
- **工作流版本管理**：无法查看工作流的历史版本
- **工作流导入/导出**：无法导入/导出工作流定义

---

## 5. 通用缺失功能

### 5.1 用户体验
- **加载状态优化**：部分操作缺少加载状态提示
- **错误处理优化**：错误提示可以更友好（如重试按钮）
- **空状态优化**：空列表可以显示引导信息
- **快捷键支持**：缺少常用操作的快捷键

### 5.2 数据展示
- **表格视图**：只有卡片视图，缺少表格视图选项
- **视图切换**：无法在卡片/列表/表格视图间切换
- **列自定义**：表格视图无法自定义显示的列

### 5.3 性能优化
- **虚拟滚动**：长列表未使用虚拟滚动，可能影响性能
- **懒加载**：详情数据可以按需加载
- **缓存策略**：列表数据可以缓存，减少重复请求

---

## 6. 优先级建议

### 🔴 高优先级（核心功能）
1. **知识库**：拖拽上传、上传进度、文档预览
2. **Skill**：启用/禁用开关（如果后端支持）
3. **轨迹**：搜索和筛选功能
4. **工作流**：执行历史分页、执行详情查看

### 🟡 中优先级（增强体验）
1. **知识库**：批量操作、文档搜索、知识库配置
2. **Skill**：搜索筛选、工具详情
3. **轨迹**：导出功能、性能分析
4. **工作流**：执行统计、触发器状态

### 🟢 低优先级（锦上添花）
1. **知识库**：统计图表、分块查看
2. **Skill**：使用统计、依赖关系
3. **轨迹**：轨迹对比、动画回放
4. **工作流**：版本管理、导入导出
