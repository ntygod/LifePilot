# Web UI 功能页面特性说明

> **模块编号**：Phase 5 — 模块 19
> **最后更新**：2026-02-27

---

## 1. 功能概述

模块 19 在 Web UI 框架（模块 18）基础上，实现四个功能管理页面，让用户通过浏览器管理知识库、技能、轨迹和工作流。

核心价值：
- 知识库可视化管理：上传文档、查看分块状态、删除文档
- Skill / MCP 一览：查看所有已注册技能和 MCP 工具，一键启用/禁用
- 轨迹回放：查看 Agent 执行过程的每一步，辅助调试和优化
- 工作流管理：查看工作流定义和执行历史，手动触发执行

---

## 2. 核心特性

### 2.1 知识库管理页

- 知识库列表：卡片视图展示所有知识库（名称、文档数、创建时间）
- 创建知识库：对话框输入名称和描述
- 文档管理：查看知识库内文档列表，支持上传新文档和删除已有文档
- 文档上传：拖拽或点击上传，支持 PDF / Word / Markdown / TXT 格式

### 2.2 Skill / MCP 管理页

- Skill 列表：卡片视图展示所有已注册 Skill（名称、描述、来源、状态）
- Skill 启用/禁用：开关控制 Skill 是否参与 Agent 推理
- MCP Server 列表：展示所有 MCP Server（名称、连接状态、工具数量）
- MCP Server 启用/禁用：开关控制 MCP Server 连接

### 2.3 轨迹回放页

- 轨迹列表：按时间倒序展示最近的 Agent 执行轨迹
- 轨迹详情：时间线视图展示每一步（动作类型、工具调用、LLM 交互）
- 步骤详情：展开查看工具调用参数、返回结果、LLM 输入/输出
- Token 统计：每条轨迹的 Token 消耗汇总

### 2.4 工作流管理页

- 工作流列表：展示所有 YAML 定义的工作流（名称、触发器、状态）
- 工作流详情：YAML 定义只读展示 + 触发器配置信息
- 手动触发：一键触发工作流执行
- 执行历史：查看工作流的历史执行记录（时间、状态、耗时）

### 2.5 A2UI 扩展组件

- Table 组件：数据表格，支持列定义和行数据渲染
- CodeBlock 组件：代码块，支持语法高亮
- Progress 组件：进度条，显示百分比和标签

---

## 3. 使用场景

### 3.1 知识库管理

用户上传项目文档到知识库，Agent 在对话中自动检索相关内容辅助回答。

### 3.2 技能调试

开发者查看 Skill 列表，禁用不需要的 Skill 以减少 Agent 推理复杂度，或启用新安装的 MCP 工具。

### 3.3 轨迹分析

用户发现 Agent 回答不准确，通过轨迹回放查看 Agent 的推理过程，定位问题步骤。

### 3.4 工作流监控

用户查看定时工作流的执行历史，确认自动化任务正常运行，必要时手动触发重新执行。

## 4. 配置项

本模块不引入新的配置项，复用模块 18 的 Web 配置（CORS、SSE 等）。

---

## 5. 限制与未来扩展

### 5.1 当前限制

- 管理页面为只读 + 开关操作，不支持在线编辑 YAML
- 知识库文档上传为同步处理，大文件可能需要等待
- 轨迹回放不支持实时跟踪（需刷新查看最新轨迹）
- 工作流管理不含可视化编辑器（YAML 编辑通过文件系统完成）

### 5.2 未来扩展

- 在线 YAML 编辑器（Monaco Editor 集成）
- 工作流可视化编辑器（拖拽节点 + 连线）
- 轨迹实时跟踪（WebSocket 推送）
- 更多 A2UI 组件（Chart、Calendar、Timeline 等）
