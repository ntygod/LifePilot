# Gateway、安全策略与多渠道交互

> 本文档从 [FEATURES.md](../FEATURES.md) 拆分而来，对应原文 §2.13 / §2.14 / §2.15 章节。

> ⚠️ 本文档描述的是目标功能设计，尚未实现。

## 1. Gateway + 中间件管道

统一所有消息通道的入口，构建可扩展的中间件管道架构。

### 1.1 设计目标

所有通道（CLI / Web / 企微 / 钉钉 / 飞书）共享同一个消息入口，中间件管道按顺序处理请求，每一层职责单一、可独立配置。

```
消息入站 → 认证鉴权 → 限流控制 → 安全检查 → 意图路由 → Agent 执行 → 审计日志 → 响应出站
```

### 1.2 管道层级

| 层级 | 中间件 | 职责 | 说明 |
|------|--------|------|------|
| 1 | AuthMiddleware | 认证鉴权 | 验证消息来源身份，支持多通道认证策略 |
| 2 | RateLimitMiddleware | 限流控制 | 按用户/通道维度限流，防止滥用 |
| 3 | SecurityMiddleware | 安全检查 | 敏感词过滤、注入检测，复用 GuardrailAdvisor |
| 4 | RouterMiddleware | 意图路由 | 根据意图分发到对应 Agent 或快速路径 |
| 5 | ExecutionMiddleware | Agent 执行 | 调用 AgentLoop 执行任务 |
| 6 | AuditMiddleware | 审计日志 | 记录请求/响应，支持合规审计 |

**创新点**：中间件可访问认知记忆。例如安全检查层可根据用户历史行为动态调整策略——信任度高的用户可以执行更多操作。

## 2. 工具分层安全策略

构建三层级的工具权限控制体系，确保 Agent 调用工具时的安全性。

### 2.1 三层策略模型

```
全局策略（Global Policy）
  └── Agent 策略（Agent Policy）
        └── 工具策略（Tool Policy）
```

| 层级 | 作用范围 | 示例 |
|------|----------|------|
| 全局策略 | 所有 Agent、所有工具 | 禁止所有工具访问系统敏感目录 |
| Agent 策略 | 特定 Agent/Skill 的所有工具 | 日程 Skill 只能调用日程相关工具 |
| 工具策略 | 特定工具的执行权限 | 文件写入工具需要用户确认 |

### 2.2 风险等级

| 等级 | 说明 | 处理方式 |
|------|------|---------|
| LOW | 只读操作，无副作用 | 自动执行 |
| MEDIUM | 有副作用但可撤销 | 自动执行，记录审计日志 |
| HIGH | 不可逆操作 | 需要用户确认后执行 |
| CRITICAL | 高风险操作 | 需要用户确认 + 二次验证 |

**与现有系统集成**：
- 复用 `GuardrailAdvisor` 进行安全检查
- 复用 `DataRedactor` 进行敏感数据脱敏
- 策略变更实时生效，无需重启

## 3. 多渠道交互

LifePilot 支持多种交互方式，随时随地使用。

### 3.1 CLI 命令行界面

基于 JLine 3 的轻量级命令行交互，无需打开浏览器，随时使用。

**交互式对话模式：**

```bash
$ lifepilot chat
LifePilot> 今天有什么安排？

📅 今日日程：
  09:00-10:00  团队周会（会议室A）
  14:00-15:30  产品评审（线上）

📋 待办事项（3 项未完成）：
  🔴 [高] 提交Q1报告 — 截止今天 18:00
  🟡 [中] 回复客户邮件
  🟢 [低] 整理文档

🎯 习惯打卡：
  ✅ 晨跑（已完成）  ⬜ 阅读（待完成）
```

**快捷命令：**

| 命令 | 说明 |
|------|------|
| `lifepilot chat` | 进入交互式对话模式 |
| `lifepilot dashboard` | 查看今日概览（日程 + 待办 + 习惯） |
| `lifepilot todo list` | 查看待办列表 |
| `lifepilot todo add "任务名"` | 快速添加待办 |
| `lifepilot schedule today` | 查看今日日程 |
| `lifepilot schedule tomorrow` | 查看明日日程 |
| `lifepilot habit status` | 查看习惯打卡状态 |
| `lifepilot habit checkin "习惯名"` | 快速打卡 |
| `lifepilot llm list` | 查看已配置的 LLM 服务商 |
| `lifepilot llm add` | 添加 LLM 服务商配置 |
| `lifepilot llm test <id>` | 测试 LLM 服务商连通性 |
| `lifepilot mcp list` | 查看已配置的 MCP Server |
| `lifepilot mcp add` | 添加 MCP Server |
| `lifepilot skill list` | 查看已注册的 Skill |
| `lifepilot config` | 管理系统配置 |
| `lifepilot version` | 显示版本信息 |

**输出特性**：彩色输出、优先级颜色区分、表格格式展示、终端自动补全。

**CLI 快速路径**：简单命令（`version`、`help`、`settings list`）跳过完整 Spring 上下文初始化，实现毫秒级响应（< 100ms）。

### 3.2 Web UI

完整的单页应用管理界面，基于 Vue 3 构建：

| 页面 | 功能 |
|------|------|
| 对话页 | 对话交互、历史记录、对话管理 |
| 知识库页 | 文档上传、文档列表、知识搜索 |
| Skill 管理页 | 内置 Skill 管理、YAML Skill 编辑、MCP Server 配置 |
| 设置页 | LLM 服务商配置、系统参数、通知偏好 |
| 轨迹回放页 | Agent 执行轨迹查看、步骤回放、决策审计 |

### 3.3 系统托盘通知

后台常驻，通过操作系统原生通知推送提醒：

- 系统托盘图标显示运行状态
- Windows / macOS / Linux 原生通知推送
- 托盘右键菜单：查看最近提醒、打开 CLI、暂停/恢复通知、退出

### 3.4 国内消息平台集成

| 平台 | 接入方式 | 特性 |
|------|---------|------|
| 企业微信 | 应用消息 | 富文本/卡片消息、消息签名验证 |
| 钉钉 | 自定义机器人/应用 | 交互式卡片、@消息触发 |
| 飞书 | 自定义机器人/应用 | 富文本消息、事件订阅 |

所有平台共享统一的消息格式转换层，体验一致。支持断线自动重连和失败消息入队重发。
