# 内置 Skills（待办 / 日程 / 习惯）

> 本文档从 [FEATURES.md](../FEATURES.md) 拆分而来，对应原文 §2.7 / §2.8 / §2.9 章节。

> ⚠️ 本文档描述的是目标功能设计，尚未实现。

## 1. 待办管理

通过自然语言管理待办事项，支持优先级、截止日期、状态筛选、智能提醒。

**功能：**
- 创建待办：支持标题、描述、优先级（高/中/低）、截止日期
- 查看列表：按优先级和截止日期排序
- 状态管理：待办 → 进行中 → 已完成，状态转换有校验
- 截止提醒：截止日期不足 24 小时自动提醒
- 智能关联：自动关联相关日程和知识图谱实体

**对话示例：**

```
你：帮我列一下这周还没完成的事情

LifePilot：📋 本周未完成待办（3 项）：

         🔴 [高] 提交Q1报告
            截止：周五 18:00（还剩 2 天）
            关联日程：周五 15:00 项目评审会

         🟡 [中] 回复张总的合作方案邮件
            截止：周四 12:00（还剩 1 天）
            💡 提示：张总上次提到预算上限是 50 万

         🟢 [低] 整理上周会议纪要
            截止：本周日
         
         建议优先处理「回复张总邮件」，明天就到期了。
```

## 2. 日程管理

自然语言管理日程安排，智能冲突检测，与待办和知识图谱联动。

**功能：**
- 创建日程：标题、开始/结束时间、地点、备注
- 冲突检测：新日程与已有日程时间冲突时自动提醒
- 事前提醒：日程开始前 15 分钟推送提醒（可配置）
- 智能建议：根据知识图谱中的信息，提供会议准备建议

**对话示例：**

```
你：明天下午3点和李总开会

LifePilot：⚠️ 明天下午 3:00-4:00 与「产品评审会」时间冲突。
         
         建议方案：
         1. 将李总的会议改到 4:30-5:30
         2. 将产品评审会提前到 1:30-2:30
         
         你想怎么安排？

你：改到4:30吧

LifePilot：✅ 已创建日程「与李总开会」，明天 16:30-17:30
         🔔 明天 16:15 会提醒你
         💡 李总上次提到对交付时间线比较关注，建议准备相关材料
```

## 3. 习惯养成

追踪和养成好习惯，连续打卡统计，智能鼓励。

**功能：**
- 创建习惯：名称、频率（每日/每周）、目标打卡时间
- 打卡记录：记录打卡时间，更新连续天数
- 统计数据：连续打卡天数、本周完成率、本月完成率
- 打卡提醒：到达设定时间自动提醒
- 鼓励机制：连续 3 天未打卡发送鼓励消息

**对话示例：**

```
你：打卡晨跑

LifePilot：🏃 晨跑打卡成功！
         🔥 连续打卡：16 天
         📊 本月完成率：85%（17/20 天）
         
         你已经连续跑了两周多了，太棒了！
         按这个节奏，月底就能达成 25 天的目标 💪
```
