## 文档信息

- **文档名称**: LifePilot Web 前端需求与交互设计文档（个人版）
- **适用项目**: `lifepilot-web`（Vue 3 + Tailwind CSS + shadcn-vue 等现代前端技术栈）
- **版本**: v1.1（单用户 / 无组织范围精简版）
- **面向读者**: 产品、前端工程师、后端工程师、测试、设计
- **适用范围**: 当前仅面向**本机单用户个人使用场景**，不包含多用户、团队、组织与资源共享能力

---

## 1. 产品概述（个人版）

- **产品定位**  
  LifePilot 是一个**本地运行的个人 AI Agent 助手**。本 Web 前端是其在浏览器中的主要交互界面。

- **当前范围（个人版）**
  - 仅支持**单用户**（假定“当前本机用户”）。
  - 不存在“组织”“团队”“成员管理”等概念。
  - 所有会话 / 知识库 / Agent / 工作流等资源默认仅该用户本人可见。
  - 将来如支持多用户/组织，会以新版本需求文档扩展，本版保持向后兼容。

- **核心价值（在单用户前提下）**
  - **对话层**: 高质量、多轮对话（Chat）与上下文管理。
  - **知识层**: 支持个人知识库构建与检索增强（RAG）。
  - **Agent / 自动化层**: 通过 Agent 和工作流执行更复杂的任务。
  - **可观测层**: 查看用量、轨迹回放，帮助用户理解和调优自己的使用。

- **目标形态（前端视角）**  
  从“单一 Chat 页”升级为一套面向**个人**的轻量控制台：  
  - 多会话、多知识库、多 Agent、多工作流在同一 UI 下可见、可管理。  
  - 暂不涉及“分享/协作/权限”，所有资源都属于当前用户。

## 2. 用户与数据范围（无组织版）

> 本节从前端视角说明“谁在用”和“数据属于谁”，当前仅考虑单人使用。

### 2.1 用户模型

- 当前只有一个有效用户：**本机使用者**。
- 无需登录 / 注册 / 邀请等流程（后续如引入账号体系再扩展）。
- “个人中心”仅作为显示/配置界面（头像、昵称、API Key 等），不涉及多账号切换。

### 2.2 资源类型

- **会话**（Conversation）
- **知识库**（Knowledge Base）
- **文档**（Document，知识库下属）
- **Agent**
- **工作流**（Workflow）

### 2.3 可见性与权限

- 所有资源默认视为 **Private**：
  - 仅当前用户在本机访问。
  - 前端无需展示“可见性切换”控件（Private / Org / Shared 等全部移除）。
- 权限控制在当前阶段极简化：
  - 所有资源默认可读写、可删除。
  - 不存在“只读成员”“管理员”等角色差异。

> 未来如扩展到多用户/组织，可在资源详情与列表中增加“归属空间 + 可见性”等字段。当前版本前端无需实现相关 UI。

## 3. 信息架构（IA，个人版）

### 3.1 一级导航（侧边或顶部导航）

- **对话**（Conversations）
- **知识库**（Knowledge Base）
- **Agent / 工作流 / 扩展**（Agents, Workflows & Extensions）
- **分析 / 用量**（Analytics）
- **设置**（Settings）

> “账号 / 组织”作为单独一级导航在本版中移除；与个人相关的资料与 API Key 等入口可放在右上角头像下拉中，也可放入设置页。

### 3.2 路由结构（示例）

- **对话**
  - `/conversations`
  - `/conversations/:id`
- **知识库**
  - `/knowledge-bases`
  - `/knowledge-bases/:id`
  - `/knowledge-bases/:id/documents/:docId`
- **Agent / 工作流 / 扩展**
  - `/agents`
  - `/agents/:id`
  - `/workflows`
  - `/workflows/:id`
  - `/skills`
  - `/skills/:id`
  - `/tools`
  - `/tools/:id`
  - `/mcp-servers`
  - `/mcp-servers/:id`
- **分析 / 用量**
  - `/analytics/usage`
  - `/analytics/agents`
- **设置**
  - `/settings/preferences`
  - `/settings/shortcuts`
  - `/settings/models`
- **个人信息（可选，入口在头像下拉或设置中）**
  - `/profile`

### 3.3 路由行为要求

- 所有详情页必须支持：
  - 浏览器前进 / 后退。
  - 深链接访问（直接访问 URL 能正确加载资源数据）。
  - 多标签页并行（同一账号不同资源页互不干扰）。
- URL 尽量稳定，后续如有结构调整需保留兼容跳转。

## 4. 对话 & 会话管理需求

> 与原版类似，但移除“空间 / 可见性 / 组织相关字段”。

### 4.1 会话列表页（`/conversations`）

#### 4.1.1 用户目标

- 快速浏览和进入历史会话。
- 搜索、整理、管理会话（重命名、归档、删除、固定）。

#### 4.1.2 功能点

- **会话列表**
  - 字段：
    - 会话名称（可编辑）。
    - 最近一条消息摘要（截断显示）。
    - 最后更新时间。
    - （可选）图标或类型标记（例如“默认 / 某 Agent / 某场景”）。
  - 展现形式：
    - 默认按置顶优先 + 最后更新时间倒序。
    - 支持分页或无限滚动（二选一即可）。

- **新建会话**
  - 顶部或右下角“新建会话”按钮。
  - 行为：
    - 调用后端创建会话，使用默认名称：`新会话 - {日期时间}`。
    - 创建成功后自动跳转到该会话详情页。

- **搜索与过滤**
  - 搜索：
    - 在列表顶部提供搜索框，可按会话名称、最近消息内容关键字搜索（由后端支持）。
  - 过滤：
    - 置顶 / 非置顶。
    - 时间范围：最近 7 天 / 30 天 / 自定义。

- **会话操作**
  - 在列表项右侧提供“更多”菜单或右键菜单：
    - 重命名。
    - 置顶 / 取消置顶。
    - 归档 / 取消归档。
    - 删除。
  - 批量操作（可选）：
    - 多选后批量归档 / 删除。

#### 4.1.3 交互与状态

- 删除会话：
  - 弹出确认对话框，需用户明确确认。
- 归档会话：
  - 归档后默认从主列表隐藏，可通过“显示归档会话”开关查看。
- Loading 骨架屏：
  - 初次进入时如果数据未返回，展示列表骨架占位。

---

### 4.2 会话详情页（`/conversations/:id`）

#### 4.2.1 用户目标

- 与 AI / Agent 进行多轮对话。
- 查看和管理该会话的配置（模型、Agent、知识库等）。

#### 4.2.2 功能点

- **消息流区域**
  - 布局：
    - 左右对齐：Assistant / Agent 在左，User 在右。
  - 每条消息展示：
    - 头像 + 角色标识（User / Assistant / Agent）。
    - 时间戳（精确到分钟）。
    - 内容（支持富文本、代码块、列表、引用等）。
    - 操作按钮区域。

- **消息级操作**
  - 复制内容。
  - 重新生成该条回复（对最近一条 AI 消息有效）。
  - 从该条消息“分叉新会话”：
    - 创建一个新会话。
    - 将当前会话到该消息为止的上下文复制过去。
  - 点赞 / 点踩：
    - 点踩时可弹出可选反馈输入框（填写问题描述）。

- **输入区**
  - 多行输入框：
    - Enter 发送，Shift+Enter 换行。
    - 输入时自动增高（一定高度后出现滚动条）。
  - 附件/上传（如果后端支持）：
    - 支持拖拽文件到输入区。
    - 显示文件预览和移除操作。
  - Prompt 模板快捷插入：
    - 下拉菜单展示常用模板和分类。
    - 选择模板后自动填充或追加到输入框。
  - 当前上下文配置（折叠区域）：
    - 当前 Agent。
    - 当前模型。
    - 温度、最大 Tokens。
    - 关联知识库。

- **会话信息侧栏**
  - 基本信息：
    - 会话名称（可编辑）、创建时间。
  - 关联资源：
    - 当前绑定 Agent（可点击跳转）。
    - 关联知识库列表（可点击跳转）。
  - 可折叠 / 固定于右侧。

#### 4.2.3 状态 & 错误反馈

- 消息生成中：
  - 显示打字机式流式输出效果。
  - 在输入区附近显示“正在思考…”状态。
  - 提供“停止生成”按钮。
- 停止生成：
  - 用户点击后立即终止流式输出。
  - 已生成部分保留。
- 错误场景：
  - 网络错误 / 超时：
    - 在消息气泡中提示“发送失败，点击重试”。
  - 后端业务错误：
    - 在消息中显示简洁错误信息。
    - 可展开查看详细错误。

## 5. 知识库模块需求

> 保留原有核心能力，移除“空间 / 可见性 / 组织”相关字段。

### 5.1 知识库列表页（`/knowledge-bases`）

#### 5.1.1 用户目标

- 管理和查找知识库资源。
- 快速了解每个知识库的状态和使用情况。

#### 5.1.2 功能点

- **知识库列表**
  - 字段：
    - 名称。
    - 简介（首行或截断）。
    - 文档数量。
    - 最后更新时间。
    - 标签（可选）。

- **新建知识库**
  - 顶部“新建知识库”按钮，打开弹窗：
    - 必填：名称。
    - 可选：描述、标签。

- **搜索 & 过滤**
  - 关键词搜索：按名称 / 描述。
  - 过滤条件：
    - 标签。
    - 更新时间范围。

- **知识库操作**
  - 重命名。
  - 修改描述、标签。
  - 删除知识库：
    - 删除前弹出确认框，提示会影响已绑定的 Agent / 会话。

---

### 5.2 知识库详情页（`/knowledge-bases/:id`）

#### 5.2.1 用户目标

- 为知识库上传、管理文档。
- 查看索引 / 向量化处理状态，验证检索质量。

#### 5.2.2 功能点

- **基本信息区**
  - 显示：
    - 名称。
    - 描述。
    - 标签。
  - 统计信息：
    - 文档数。
    - 分段数。
    - 索引状态（健康 / 处理中 / 部分失败）。

- **文档列表**
  - 字段：
    - 文档名称。
    - 类型（PDF / Word / Markdown / URL…）。
    - 大小。
    - 上传时间。
    - 处理状态（等待 / 处理中 / 已完成 / 失败）。
    - 最后处理时间。
  - 功能：
    - 搜索（按名称）。
    - 过滤（类型 / 状态 / 上传时间）。

- **上传入口**
  - 拖拽区域 + “上传文件”按钮。
  - 支持多文件上传。
  - 上传中显示进度条，每个文件独立进度和取消按钮。

- **文档操作**
  - 查看处理日志（解析 / 切分 / 向量化等的结果与报错）。
  - 重新索引 / 重新处理。
  - 删除文档。

- **分段 / 预览**
  - 点击某个文档进入预览侧栏或新页：
    - 左侧原文预览（如后端可返回）。
    - 右侧展示若干分段示例（内容片段、token 数、顺序）。

- **测试检索**
  - 在知识库详情页底部或侧边提供“测试问答”区域：
    - 输入一个问题，调用后端检索接口。
    - 展示命中的分段：内容 + 相似度 / 评分。
    - 如有生成能力，同时展示基于知识库的回答。

## 6. Agent & 工作流模块

> 此处与原版基本一致，仅删除与“组织 / 多用户”相关的描述。

### 6.1 Agent 列表页（`/agents`）

#### 6.1.1 功能点

- 列表字段：
  - 名称。
  - 描述。
  - 类型（通用 / 领域）。
  - 绑定模型。
  - 关联知识库数量。
  - 最后修改时间。
  - 状态（启用 / 禁用）。
- 支持搜索（名称 / 描述关键字）。

- 提供“新建 Agent”按钮。

---

### 6.2 Agent 配置详情页（`/agents/:id`）

#### 6.2.1 用户目标

- 配置 Agent 的行为（Prompt、模型、能力、工具、知识库等）。
- 调试 Agent 输出，验证效果。

#### 6.2.2 核心区域

- **基本信息**
  - 名称（必填）。
  - 图标 / 头像（可选）。
  - 简介（用于列表说明）。
  - 标签（用于分类筛选）。

- **系统提示词（System Prompt）编辑区**
  - Markdown 文本编辑器，支持多行编辑。
  - 自动保存：编辑时显示“已保存 / 保存中”状态。
  - 简易版本管理（可选）：
    - 每次显式点击“保存”时记录一个版本。
    - 可在侧栏查看历史版本列表并一键回滚（需确认）。

- **模型与参数**
  - 下拉选择模型（从系统模型列表中选择）。
  - 参数配置：
    - 温度。
    - 最大 Token。
    - Top-p（如需要）。
  - 提供 Tooltip 解释参数含义和推荐范围。

- **关联知识库**
  - 多选知识库控件。
  - 对每个知识库可设置：
    - Top-K。
    - 最大上下文 Tokens（可选）。

- **工具 / 能力开关**
  - 列出可用工具列表。
  - 每项为开关控件，并可配置部分参数（如 API endpoint）。

- **测试对话区**
  - 页面右侧或底部的 Chat 区域：
    - 仅与当前 Agent 对话（不计入普通会话列表或以特殊标记区分）。
    - 支持查看调用日志：
      - 本次回答调用了哪些知识库 / 工具。
      - 主要中间结果（简化版）。

#### 6.2.3 操作

- 启用 / 禁用 Agent（开关按钮）。
- 保存配置：
  - 校验必填字段。
  - 显示成功 / 失败 toast。

### 6.4 Skill 管理（`/skills`, `/skills/:id`）

> 面向高级用户，用于管理 YAML Skill / 插件 Skill 等扩展能力。

#### 6.4.1 Skill 列表页（`/skills`）

- **用户目标**
  - 查看当前系统中可用的所有 Skill。
  - 对“用户自定义 Skill”执行创建 / 编辑 / 删除 / 启用 / 禁用等操作。

- **列表字段**
  - 名称。
  - 简介 / 描述。
  - 类型：
    - 内置（BUILTIN，系统自带，只读）。
    - YAML（USER_DEFINED，本地 YAML Skill）。
    - MCP（来自某个 MCP Server 暴露的工具，可读）。
  - 来源：
    - `core`（内置）。
    - `~/.lifepilot/skills`（用户 YAML）。
    - `mcp:{serverName}`（MCP Tool 映射）。
  - 状态：启用 / 禁用。
  - 最后修改时间（用户自定义 Skill）。

- **操作能力**
  - 对 **用户自定义 YAML Skill**：
    - 新建 Skill（跳转到创建表单或编辑器）。
    - 编辑 Skill。
    - 删除 Skill（需确认）。
    - 启用 / 禁用。
  - 对 **内置 Skill**：
    - 仅允许启用 / 禁用，不支持删除或直接编辑。
  - 对 **MCP 来源的 Skill**：
    - 只读查看元数据和映射关系（如对应 MCP server + toolId）。

#### 6.4.2 Skill 详情 / 编辑页（`/skills/:id`）

- **基础信息**
  - 名称（必填）。
  - 描述。
  - 标签。
  - 类型（只读）。
  - 来源（只读）。

- **YAML Skill 配置编辑区（仅 YAML 类型可编辑）**
  - 以 YAML 编辑器形式展示完整配置：
    - 输入 / 输出 schema。
    - 绑定的 ToolContract / 调用方式。
    - 允许访问的记忆 / 知识库范围（如果有）。
  - 提供基础的语法高亮与格式校验（后端可选做服务端校验）。

- **调试区域（可选）**
  - 提供一个简单的测试面板：
    - 填写输入参数。
    - 调用 Skill 并展示执行结果 / 错误信息。

- **操作**
  - 保存（更新 YAML 文件或后端存储）。
  - 启用 / 禁用 Skill。
  - 删除 Skill（仅用户自定义；需确认）。

### 6.5 Tool 管理（`/tools`, `/tools/:id`）

> 对应后端的 `DynamicToolRegistry` 等能力，提供统一视图管理所有工具（包括 Java 原生、YAML Skill 绑定、MCP 工具）。

#### 6.5.1 Tool 列表页（`/tools`）

- **用户目标**
  - 统一查看当前系统中可用的所有工具（Tool）。
  - 理解每个工具的来源、类型和风险级别。
  - 对部分工具执行启用 / 禁用、配置修改等操作。

- **列表字段**
  - 名称（工具标识）。
  - 显示名（可读性名称）。
  - 类型：
    - Java 原生（PLUGIN）。
    - YAML Skill 绑定（SKILL）。
    - MCP 工具（MCP）。
  - 来源：
    - 对应 Skill 名称 / MCP Server 名称等。
  - 风险等级（Low / Medium / High，由后端提供）。
  - 状态：启用 / 禁用。

- **操作能力**
  - 针对不同类型的工具：
    - **Java 原生 / 内置工具**：
      - 支持启用 / 禁用。
      - 不支持删除。
    - **通过 YAML Skill 生成的工具**：
      - 在工具详情中可跳转到对应 Skill 编辑页面。
      - 删除/编辑逻辑在 Skill 页面完成。
    - **MCP 工具**：
      - 只读查看元数据和映射关系。
  - 通用操作：
    - 搜索（按名称 / 类型 / 来源）。
    - 按类型 / 状态 / 风险等级过滤。

#### 6.5.2 Tool 详情页（`/tools/:id`）

- **基础信息**
  - 工具 ID（只读）。
  - 名称 / 显示名。
  - 类型（只读）。
  - 来源（Skill 名称、MCP server + toolId、内置模块等）。
  - 风险等级（只读或从后端配置）。

- **行为与约束说明（只读）**
  - 简要描述工具的功能。
  - 对潜在副作用给出提示（如“会写入本地文件”“会发起网络请求”等）。

- **配置与开关**
  - 启用 / 禁用工具（如后端支持）。
  - 针对某些可配置工具，展示参数配置表单（例如 API Endpoint、超时时间等）。

- **调试（可选）**
  - 简单测试调用界面：
    - 输入参数 JSON（或表单）。
    - 查看调用结果。

---

### 6.6 MCP Server 管理（`/mcp-servers`, `/mcp-servers/:id`）

> 对 `lifepilot.mcp.servers` 配置的可视化管理，支持新增 / 修改 / 删除 / 测试 MCP Server。

#### 6.6.1 MCP Server 列表页（`/mcp-servers`）

- **用户目标**
  - 查看当前配置的 MCP Server 列表。
  - 新增、编辑或删除 MCP Server 配置。
  - 快速测试 MCP Server 连接与可用工具列表。

- **列表字段**
  - 名称（唯一标识，如 `filesystem`、`github`）。
  - 传输方式（stdio / sse 等）。
  - 连接信息概要：
    - 对于 stdio：command + args 简要展示。
    - 对于 sse / http：基础 URL。
  - 状态（最近一次连接测试结果：成功 / 失败 / 未测试）。
  - 最后测试时间。

- **操作能力**
  - 新建 MCP Server。
  - 编辑 MCP Server。
  - 删除 MCP Server（需确认，并提示可能影响依赖该 MCP 的 Skill / Tool）。
  - 测试连接：
    - 调用后端测试接口。
    - 返回测试结果（成功 / 错误信息）。
    - 可选展示该 Server 暴露的工具列表摘要。

#### 6.6.2 MCP Server 详情 / 编辑页（`/mcp-servers/:id`）

- **基础配置表单**
  - 名称（必填，唯一，创建后一般只读）。
  - 传输方式：
    - stdio。
    - sse / http。
  - 当为 stdio 时：
    - command。
    - args（数组形式编辑）。
    - 工作目录（可选）。
  - 当为 sse / http 时：
    - base URL。
    - 认证方式（如有，后续可扩展）。

- **高级选项（可选）**
  - 启动超时时间。
  - 最大并发。
  - 重试策略等（如后端有支持）。

- **调试与工具浏览**
  - “测试连接”按钮：
    - 调用后端测试接口并展示结果。
  - “查看工具列表”：
    - 展示该 MCP Server 当前暴露的 Tool 列表（名称 / 描述 / 参数等摘要）。
    - 可跳转到 Tool 列表页中对应 Tool 的详情。

- **操作**
  - 保存（创建 / 更新）。
  - 删除（需确认）。
  - 测试连接。

## 10. 通用交互与 UX 规范（与 UI 文档对齐）

> 与 `docs/ui-design-optimization.md` / Web UI 设计规范配合使用。

### 10.1 布局与间距

- 全局采用统一的：
  - 页面最大宽度。
  - 栅格 / 分栏系统。
  - 间距与层级（Margin / Padding / Elevation）。

### 10.2 状态反馈

- 所有异步操作（创建 / 更新 / 删除 / 上传 / 执行工作流）必须提供：
  - 明确的进行中状态（按钮 loading、全局进度条等）。
  - 成功 / 失败 toast 提示。

### 10.3 错误处理

- 全局错误（网络中断等）：
  - 统一全局提示组件（如顶部条幅 / 模态框）。
  - 提供“重试”按钮（无登录时无需“重新登录”）。
- 局部错误：
  - 在对应组件内显示错误提示，不影响全局其他区域使用。

### 10.4 国际化

- 所有展示文案通过 i18n 管理。
- 至少支持中 / 英两种语言切换。

## 11. 埋点与统计（简要说明）

> 具体字段由数据/产品协商，此处为前端需要预留的事件类型。即使本地单用户，也可以用于本地日志分析、调试与未来云同步预留。

### 11.1 核心事件

- 会话相关：
  - 新建会话。
  - 发送消息。
  - 重命名会话。
  - 归档 / 删除会话。
  - 分叉新会话。
- 知识库相关：
  - 新建知识库。
  - 上传文档。
  - 删除文档。
  - 重建索引。
  - 测试检索。
- Agent 相关：
  - 新建 Agent。
  - 修改 Agent 配置。
  - 启用 / 禁用 Agent。
  - 调试调用（测试对话）。
- 设置：
  - 修改主题 / 语言 / 快捷键配置。

### 11.2 推荐参数

- `conversation_id`
- `kb_id`
- `doc_id`
- `agent_id`
- `workflow_id`
- `from_page`（触发来源页面）

> 原文中的 `user_role`、`org_id` 等多用户 / 组织相关参数在本版中暂不需要。

## 12. 非功能性需求（前端相关）

### 12.1 性能

- 核心页面首屏渲染时间在合理范围内（依实际部署环境设定目标）。
- 长列表使用虚拟滚动或分页，避免一次性加载过多数据。

### 12.2 可用性

- 关键路径（对话、上传文档、Agent 调试）在网络波动下具备良好的重试与恢复机制。

### 12.3 可维护性

- 路由、状态管理、接口层结构清晰，模块划分合理，便于迭代与后续从“个人版”升级到“多用户版”。
