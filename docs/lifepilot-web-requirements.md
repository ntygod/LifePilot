## 1. 产品概述

- **产品定位**  
  LifePilot 是一个支持多会话、多知识库、多 Agent、多用户 / 团队协作的 AI 助理与知识工作平台。

- **核心价值**
  - **对话层**: 提供高质量、多轮对话（Chat）与上下文管理。
  - **知识层**: 支持企业与个人知识库构建与检索增强（RAG）。
  - **Agent / 自动化层**: 通过 Agent 和工作流执行更复杂的任务（多步骤、调用工具）。
  - **协作与治理层**: 团队与权限管理、用量监控、反馈闭环。

- **目标形态（前端视角）**  
  从「单一 Chat 页」升级为一套支持多会话、多知识库、多 Agent、多用户 / 团队的 **产品控制台**，并满足：可分享、可协作、可运营、可观测。

## 2. 用户角色与权限模型（前端视角）

> 最终以后端权限模型为准，此处定义前端需要体现和依赖的最小集合。

### 2.1 角色类型（最少）

- **Owner**
  - 拥有组织的全部管理权限（包括删除组织、管理计费等）。
  - 全部资源的读写删除权限。
- **Admin**
  - 管理组织成员（邀请、移除、调角色）。
  - 管理团队级资源（知识库、Agent、工作流等），但无法删除 Owner 和组织本身。
- **Member**
  - 使用产品核心功能。
  - 访问自己或被授予访问权限的资源。

> 若实际还有 Guest / Viewer 等角色，可在实现时补充映射。

### 2.2 资源类型

- **会话**（Conversation）
- **知识库**（Knowledge Base）
- **文档**（Document，知识库下属）
- **Agent**
- **工作流**（Workflow）

### 2.3 可见性级别

- **仅自己可见**（Private）
- **本组织可见**（Organization）
- **指定成员 / 团队**（Shared，基于成员或团队维度）

### 2.4 前端展示原则

- **能看见 ≈ 有权访问**  
  - 前端应根据用户权限控制资源是否显示和可操作，尽量避免“点了才报错”的体验。
- **资源详情页必须展示：归属空间 + 权限信息**  
  - 如：`个人空间 / 组织名称 / 所属团队` + `可见性：仅自己 / 组织 / 指定成员`。
- **操作级权限控制**
  - 没有权限的操作按钮应隐藏或禁用，并附带相应说明 Tooltip（如“仅 Admin 可编辑”）。

## 3. 信息架构（IA）

### 3.1 一级导航（顶部或侧边导航）

- **对话**（Conversations）
- **知识库**（Knowledge Base）
- **Agent / 工作流**（Agents & Workflows）
- **分析 / 用量**（Analytics）
- **设置**（Settings）
- **账号 / 组织**（Profile & Organization）

> 实际布局（顶部导航 + 侧栏）由 UI 设计最终确定，此处约束“信息分区”和“路由入口”。

### 3.2 路由结构（示例）

- **对话**
  - `/conversations`
  - `/conversations/:id`
- **知识库**
  - `/knowledge-bases`
  - `/knowledge-bases/:id`
  - `/knowledge-bases/:id/documents/:docId`
- **Agent / 工作流**
  - `/agents`
  - `/agents/:id`
  - `/workflows`
  - `/workflows/:id`
- **分析 / 用量**
  - `/analytics/usage`
  - `/analytics/agents`
- **设置**
  - `/settings/preferences`
  - `/settings/shortcuts`
  - `/settings/models`
- **账号 / 组织**
  - `/profile`
  - `/organization`
  - `/organization/members`

### 3.3 路由行为要求

- 所有详情页必须支持：
  - 浏览器前进 / 后退。
  - 深链接访问（直接访问 URL 能正确加载资源数据）。
  - 多标签页并行（同一账号不同资源页互不干扰）。
- URL 应相对稳定，后续迭代尽量避免变动；若变动需保留兼容跳转。

## 4. 对话 & 会话管理需求

### 4.1 会话列表页（`/conversations`）

#### 4.1.1 用户目标

- 快速浏览和进入历史会话。
- 搜索、整理、管理会话（重命名、归档、删除、固定）。

#### 4.1.2 功能点

- **会话列表**
  - 字段：
    - 会话名称（可编辑）。
    - 最近一条消息摘要（截断显示）。
    - 最后更新时间。
    - 所属空间（个人 / 组织）。
    - 可见性图标（Private / Org / Shared）。
    - 是否置顶标记。
  - 展现形式：
    - 默认按置顶优先 + 最后更新时间倒序。
    - 支持分页或无限滚动（视数据量和实现成本选择一种）。

- **新建会话**
  - 顶部或右下角“新建会话”按钮。
  - 行为：
    - 调用后端创建会话，使用默认名称：`新会话 - {日期时间}`。
    - 创建成功后自动跳转到该会话详情页。

- **搜索与过滤**
  - 搜索：
    - 在列表顶部提供搜索框，可按会话名称、最近消息内容关键字搜索（具体由后端实现）。
  - 过滤：
    - 置顶 / 非置顶。
    - 空间：个人 / 组织。
    - 时间范围：最近 7 天 / 30 天 / 自定义。

- **会话操作**
  - 在列表项右侧提供“更多”菜单或右键菜单：
    - 重命名。
    - 置顶 / 取消置顶。
    - 归档 / 取消归档。
    - 删除。
    - 设置可见性（Private / Org / Shared）。
  - 批量操作（可选）：
    - 切换多选模式后，支持对选中会话批量归档 / 删除。

#### 4.1.3 交互与状态

- 删除会话：
  - 弹出确认对话框，需用户明确确认。
  - 若会话被他人引用（如分享链接），提示可能影响他人访问。
- 归档会话：
  - 归档后默认从主列表隐藏，可通过“显示归档会话”开关查看。
- Loading 骨架屏：
  - 初次进入时，如果接口未返回数据，展示列表骨架占位。

---

### 4.2 会话详情页（`/conversations/:id`）

#### 4.2.1 用户目标

- 与 AI / Agent 进行多轮对话。
- 查看和管理该会话的配置（模型、Agent、知识库等）。

#### 4.2.2 功能点

- **消息流区域**
  - 布局：
    - 左右对齐：Assistant / Agent 在左，User 在右。
  - 每条消息展示：
    - 头像 + 角色标识（User / Assistant / Agent）。
    - 时间戳（精确到分钟）。
    - 内容（支持富文本、代码块、列表、引用等）。
    - 操作按钮区域。

- **消息级操作**
  - 复制内容。
  - 重新生成该条回复（对最近一条 AI 消息有效）。
  - 从该条消息“分叉新会话”：
    - 创建一个新会话。
    - 将当前会话到该消息为止的上下文复制过去。
  - 点赞 / 点踩：
    - 点踩时可弹出可选反馈输入框（填写问题描述）。

- **输入区**
  - 多行输入框：
    - Enter 发送，Shift+Enter 换行。
    - 输入时自动增高（一定高度后出现滚动条）。
  - 附件/上传（如果后端支持）：
    - 支持拖拽文件到输入区。
    - 显示文件预览和移除操作。
  - Prompt 模板快捷插入：
    - 提供下拉菜单，展示常用模板和分类。
    - 选择模板后自动填充或追加到输入框。
  - 当前上下文配置：
    - 折叠区域展示 / 编辑：
      - 当前 Agent。
      - 当前模型。
      - 温度、最大 Tokens。
      - 关联知识库。

- **会话信息侧栏**
  - 基本信息：
    - 会话名称（可编辑）、创建时间、归属空间、可见性。
  - 关联资源：
    - 当前绑定 Agent（可点击跳转）。
    - 关联知识库列表（可点击跳转）。
  - 可折叠 / 固定于右侧。

#### 4.2.3 状态 & 错误反馈

- 消息生成中：
  - 显示打字机式流式输出效果。
  - 在输入区附近显示“正在思考…”状态。
  - 提供“停止生成”按钮。
- 停止生成：
  - 用户点击后立即终止流式输出。
  - 已生成部分保留。
- 错误场景：
  - 网络错误 / 超时：
    - 在消息气泡中提示“发送失败，点击重试”。
  - 后端业务错误：
    - 在消息中显示错误信息（简洁版）。
    - 可查看详细错误（例如展开查看）。

## 5. 知识库模块需求

### 5.1 知识库列表页（`/knowledge-bases`）

#### 5.1.1 用户目标

- 管理和查找知识库资源。
- 快速了解每个知识库的状态和使用情况。

#### 5.1.2 功能点

- **知识库列表**
  - 字段：
    - 名称。
    - 简介（首行或截断）。
    - 文档数量。
    - 最后更新时间。
    - 归属空间。
    - 可见性。
    - 使用中的 Agent 数量（如方便从后端获取）。

- **新建知识库**
  - 顶部“新建知识库”按钮，打开弹窗：
    - 必填：名称。
    - 可选：描述、标签、空间、可见性。

- **搜索 & 过滤**
  - 关键词搜索：按名称 / 描述。
  - 过滤条件：
    - 标签。
    - 空间（个人 / 组织）。
    - 可见性。
    - 更新时间范围。

- **知识库操作**
  - 重命名。
  - 修改描述、标签。
  - 修改可见性。
  - 删除知识库：
    - 删除前弹出确认框，提示会影响已绑定的 Agent / 会话。

---

### 5.2 知识库详情页（`/knowledge-bases/:id`）

#### 5.2.1 用户目标

- 为知识库上传、管理文档。
- 查看索引 / 向量化处理状态，验证检索质量。

#### 5.2.2 功能点

- **基本信息区**
  - 显示：
    - 名称。
    - 描述。
    - 标签。
    - 归属空间。
    - 可见性。
  - 统计信息：
    - 文档数。
    - 分段数。
    - 索引状态（健康 / 处理中 / 部分失败）。

- **文档列表**
  - 字段：
    - 文档名称。
    - 类型（PDF / Word / Markdown / URL…）。
    - 大小。
    - 上传人。
    - 上传时间。
    - 处理状态（等待 / 处理中 / 已完成 / 失败）。
    - 最后处理时间。
  - 功能：
    - 搜索（按名称）。
    - 过滤（类型 / 状态 / 上传时间）。

- **上传入口**
  - 拖拽区域 + “上传文件”按钮。
  - 支持多文件上传。
  - 上传中显示进度条，每个文件有独立进度和取消按钮。

- **文档操作**
  - 查看处理日志（解析 / 切分 / 向量化等的结果与报错）。
  - 重新索引 / 重新处理。
  - 删除文档。

- **分段 / 预览**
  - 点击某个文档进入预览侧栏或新页：
    - 左侧原文预览（如后端可返回）。
    - 右侧展示若干分段示例（内容片段、token 数、顺序）。
  - 用于验证切分是否合理。

- **测试检索**
  - 在知识库详情页底部或侧边提供“测试问答”区域：
    - 输入一个问题，调用后端检索接口。
    - 展示命中的分段：内容 + 相似度 / 评分。
    - 如有回答生成能力，同时展示基于知识库的回答。

## 6. Agent & 工作流模块

### 6.1 Agent 列表页（`/agents`）

#### 6.1.1 功能点

- 列表字段：
  - 名称。
  - 描述。
  - 类型（通用 / 领域）。
  - 绑定模型。
  - 关联知识库数量。
  - 创建人。
  - 最后修改时间。
  - 状态（启用 / 禁用）。
- 支持搜索（名称 / 描述关键字）。
- 支持按标签 / 状态过滤。
- 提供“新建 Agent”按钮。

---

### 6.2 Agent 配置详情页（`/agents/:id`）

#### 6.2.1 用户目标

- 配置 Agent 的行为（Prompt、模型、能力、工具、知识库等）。
- 调试 Agent 输出，验证效果。

#### 6.2.2 核心区域

- **基本信息**
  - 名称（必填）。
  - 图标 / 头像（可选）。
  - 简介（用于列表说明）。
  - 标签（用于分类筛选）。

- **系统提示词（System Prompt）编辑区**
  - Markdown 文本编辑器，支持多行编辑。
  - 自动保存：编辑时显示“已保存 / 保存中”状态。
  - 简易版本管理：
    - 每次显式点击“保存”时记录一个版本。
    - 可在侧栏查看历史版本列表。
    - 支持一键回滚到旧版本（回滚前需确认）。

- **模型与参数**
  - 下拉选择模型（从系统模型列表中选择）。
  - 参数配置：
    - 温度。
    - 最大 Token。
    - Top-p（如需要）。
  - 配置说明 Tooltip：解释各参数的含义和推荐范围。

- **关联知识库**
  - 多选知识库控件。
  - 对每个知识库可设置：
    - Top-K。
    - 最大上下文 Tokens（可选）。

- **工具 / 能力开关**
  - 列出可用工具列表（如：日程、搜索、文件读取、自定义 API 等）。
  - 每项为开关控件，并可配置部分参数（如 API endpoint）。

- **测试对话区**
  - 页面右侧或底部的 Chat 区域：
    - 仅与当前 Agent 对话（不影响普通会话列表）。
    - 支持查看调用日志：
      - 本次回答调用了哪些知识库 / 工具。
      - 主要中间结果（简化版）。

#### 6.2.3 操作

- 启用 / 禁用 Agent（开关按钮）。
- 保存配置：
  - 校验必填字段。
  - 显示成功 / 失败 toast。

---

### 6.3 工作流列表及详情（`/workflows`, `/workflows/:id`）

> 若后端已提供工作流 / 编排能力，则前端需实现可视化；若暂无，则可以实现“占位版”（列表 + 详情只读），为后续扩展预留空间。

#### 6.3.1 列表需求

- 列表字段：
  - 名称。
  - 描述。
  - 触发方式（手动 / API / 定时）。
  - 运行次数。
  - 最近一次运行状态。

#### 6.3.2 详情需求

- 基本信息：名称、描述、触发方式。
- 流程结构：
  - 以列表或简单可视化形式展示步骤（顺序 / 条件节点）。
  - 展示每个步骤绑定的 Agent / 工具信息。
- 操作：
  - 手动触发运行。
  - 查看运行记录：
    - 输入 / 输出摘要。
    - 结果状态。
    - 错误信息（如有）。

  - 为不同空间 / 团队指定默认模型。

### 8.3 快捷键设置（`/settings/shortcuts`）

#### 8.3.1 功能点

  - 全局快捷键：如打开命令面板、切换主题等。
  - 对话页快捷键：新建会话、聚焦输入框、发送消息等。
  - 编辑器快捷键：代码块复制、折叠等。
- 支持部分快捷键自定义（若后端支持持久化）：
  - 点击某条快捷键进入编辑模式。
  - 监听用户按下新的组合键，保存更新。

## 11. 通用交互与 UX 规范（与 UI 文档对齐）

> 与 `docs/ui-design-optimization.md` 中的 UI 规范配合使用。

### 11.1 布局与间距

- 全局采用统一的：
  - 页面最大宽度。
  - 栅格 / 分栏系统。
  - 间距与层级（Margin / Padding / Elevation）。

### 11.2 状态反馈

- 所有异步操作（创建 / 更新 / 删除 / 上传 / 执行工作流）必须提供：
  - 明确的进行中状态（按钮 loading、全局进度条等）。
  - 成功 / 失败 toast 提示。

### 11.3 错误处理

- 全局错误（鉴权失败、网络中断）：
  - 统一全局提示组件（如顶部条幅 / 模态框）。
  - 提供“重新登录 / 重试”按钮。
- 局部错误：
  - 在对应组件内显示错误提示，不影响全局其他区域正常使用。

### 11.4 国际化

- 所有展示文案通过 i18n 管理。
- 至少支持中 / 英两种语言切换。

## 13. 非功能性需求（前端相关）

### 13.1 性能

- 核心页面首屏渲染时间（TTFB + 渲染）在合理范围内（依实际部署环境设定目标）。
- 长列表使用虚拟滚动或分页，避免一次性加载过多数据。

### 13.2 可用性

- 关键路径（对话、上传文档、Agent 调试）在网络波动下，具备良好的重试与恢复机制。

### 13.3 可维护性

- 路由、状态管理、接口层结构清晰，模块划分合理，便于多人协作与迭代。
