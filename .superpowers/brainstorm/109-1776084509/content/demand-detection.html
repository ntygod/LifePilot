② 需求检测层 — 三级过滤

关键省钱层：大部分心跳在这里就结束了，不调 LLM

心跳唤醒 / 事件触发
▼
第一关：变化量检查（纯规则，0 成本）
对比上次心跳的 ContextPacket，检查：
• 记忆层有新增/更新吗？
• 有新的外部数据到达吗？（天气变化、剪贴板变化）
• 有时间窗口触发吗？（接近截止日、习惯时段到了）
• 意图记忆的触发条件满足了吗？
▼ 无变化
🔇 SILENT
记录心跳日志，休眠
预估 80% 心跳到此结束
▼ 有变化
↓
第二关：快速打分（规则 + 现有打分模型，0 LLM 成本）
对变化的信号跑现有的 ReminderScoringModel 公式：
30% 证据 + 25% 时机 + 20% 紧迫 + 15% 适配 + 10% 可行
每个行为插件快速报告：有无候选 + 粗略分数
▼ 分数 < 0.4
⚡ FAST
用缓存上下文生成轻量响应
或排队到下次对话
预估 15% 心跳到此
▼ 分数 ≥ 0.4
↓
第三关：完整 LLM 推理（仅 ~5% 心跳走到这里）
• 携带完整上下文调用 LLM
• 生成思维链（为什么现在要主动、要做什么）
• 输出：主动分数(1-5) + 动作类型 + 生成内容
• 透明性：思维链保存到决策日志，可解释
▼
🧠 FULL → 进入统一决策门控
